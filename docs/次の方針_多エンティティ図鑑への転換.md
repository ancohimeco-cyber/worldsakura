# 次の方針 ― 多エンティティ図鑑への転換（作業指示）

宛先：worldsakura を継続して作る担当（別PCのエージェント含む）
日付：2026-08-31 ／ 出した人：さくら（もう1台のPC側で相談してまとめたもの）

---

## 何がズレているか

いまのサイトは「国ディレクトリ」として綺麗に動いている。ありがとう。
ただ、さくらが作りたいのは **「大きな世界の図鑑」＝ジャンルの扉がいくつもあって、
その中に世界中のモノが入っている** もの。

現状は `data/countries.json` の1データ型しかなく、`flags.html` も `animals.html` も
`category-list.js` で **193か国をABC順に並べて国オブジェクトの一部を見せているだけ**。
だから「動物・自然」の扉に入っても、出てくるのは動物ではなく国。ここを直したい。

詳細は `docs/SPEC.md`（多エンティティ図鑑版）と `docs/ROADMAP.md` を見てください。

---

## やってほしいこと（この順で）

### ステップ1：パイロットとして「動物」の扉をエンティティ方式で作る

**国ABC順にしない。動物ごとの一覧にする。**

1. `data/animals.json` を新設。1件＝1動物：
   ```json
   {
     "key": "giant_panda",
     "name": "ジャイアントパンダ",
     "nameEn": "Giant Panda",
     "type": "哺乳類",
     "iucn": "危急",
     "countries": ["cn"],
     "isNationalAnimalOf": [],
     "blurb": "…(出典のある説明)…",
     "img": "assets/img/animals/giant_panda.jpg",
     "sources": [{ "url": "…", "checked": "2026-08-31" }]
   }
   ```
2. まず 50〜80種（各国の国獣＋誰でも知っている有名種）を**出典付きで**投入。
   memory で書かない・作らない（さくらの共通ルール）。
3. `assets/js/animals.js` を作る：
   - タブ：種類（哺乳類/鳥/爬虫類/両生類/魚/昆虫）／大陸／希少度
   - 動物カードの一覧（名前・サムネ・「生息 🇰🇪🇹🇿」・希少度バッジ）
   - カード→詳細（説明／生息国リンク→ `country.html?id=` ／国獣バッジ）
4. `animals.html` を `category-list.js` から `animals.js` に差し替え。
5. `country.js`：国ページの「動物」欄を、`animals.json` を `code` で join して表示に変更。
6. `data/countries.json` から `animals` 文字列配列を削除（正本を animals.json に一元化）。
7. 逆引き検索（`search.js`）の「生息動物」タブ：ヒット時に**動物カード**を出す（今は国カード）。

これで「扉に入ると主役が変わる」形の実例が1つできる。さくらに見せて方向を確認。

## 触ってはいけない / 注意

- 国番号（`id`）は既存動画基準で確定済み。**変えない。** コンゴ共和国は `data/_parked/cg.json` のまま。
- 193の国旗SVG・国レイヤーは資産。作り直さない、上に足す。
- `b4f8b03` で一般知識補完した193か国データは**未検証**。扉を作り込むとき、その扉が使う項目を出典付きで直す。
- 大きな一括作り直しはしない。1扉ずつ。
