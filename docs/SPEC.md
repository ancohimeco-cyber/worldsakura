# worldsakura.com 制作仕様（SPEC）― 多エンティティ図鑑版

`docs/企画リサーチ.md`（設計図）から実装へ落とした仕様。
**2026-08-31 改訂：「国だけが主役」から「国・生き物・国旗・ことば…が並列で主役」の多エンティティ設計へ転換。**

---

## 0. これは何を直す改訂か

現状（commit `b4f8b03` 時点）のサイトは、**データの単位が「国」1種類しかない**。

- `data/countries.json` が唯一のデータセット
- 全カテゴリーページ（`flags.html` / `animals.html` …）が `category-list.js` で
  **193か国をアルファベット順に並べ、国オブジェクトの一部フィールドだけ表示**する作り
- 逆引き検索で「パンダ」を引いても、結果は「中国（国カード）」であって「パンダ」ではない

→ どの扉から入っても行き着く先が「国のカード」。
「大きな世界の図鑑」＝いろんなジャンルの扉があって、その中に世界中のモノが入っている、
という狙いに対して構造が足りていない。本SPECはそこを設計しなおす。

---

## 1. サイトの位置づけ

> 193か国を、国・国旗・首都・ことば・生きもの・旅・雑学 ─ いろんな入口から巡る**世界の図鑑**

- ancohime.com とは完全に別サイト・別ドメイン・別リポジトリ・別アドセンス。
- 静的サイト（HTML＋JSON＋クライアントJS）。ビルド不要。GitHub Pages。
- **国は「図鑑の1章」であって、図鑑そのものではない。**

---

## 2. ナビゲーションは2軸

| 軸 | 入口 | 主役 | 例 |
|---|---|---|---|
| **縦（国）** | `/countries.html` → `/country.html?id=85` | その国のすべて | 「日本」の首都・通貨・動物・ことば… |
| **横（テーマ）** | `/animals.html` `/flags.html` … | そのテーマのモノ | 「世界の生きもの」＝動物ごとに一覧、国はタグ |

- トップページ（`index.html`）は**両方への扉を等しく並べる**ハブ。国一覧は扉の1つ。
- どの横テーマページも「国をABC順に並べる」構成にしてはいけない。**主役はテーマ側のエンティティ。**

---

## 3. エンティティ型（それぞれ独立したデータ＋一覧＋詳細）

| 型 | データ | 一覧ページ | 主な属性 | 国との関係 |
|---|---|---|---|---|
| `country` | `data/countries.json` | `/countries.html` | id(1-193) / code(iso2) / 首都 / 人口 / 通貨 / 政体 / 面積 / 気候 … **国固有の事実のみ** | 本体 |
| `animal` | `data/animals.json` | `/animals.html` | name / type(哺乳類…) / iucn(危急…) / countries[iso2] / blurb / img | `countries[]` で参照 |
| `flag_motif` | `data/flag_motifs.json` | `/flags.html` | key / label(「三日月と星」) / meaning / countries[iso2] | `countries[]` で参照 |
| `phrase` | `data/phrases.json` | `/words.html` | key(「ありがとう」) / by language: {lang, text, pron, family, countries[]} | language 経由 |
| `heritage` | `data/heritage.json` | （当面 `/culture.html` 内） | name / country / type(文化/自然) / year / blurb | `country` 単数 |
| `capital` | `countries.json` 流用 | `/capitals.html` | 首都名 / 人口 / 標高 / 内陸or港湾 / 地図ネタ | 1国1首都 |
| `dish` | `data/dishes.json`（後） | `/food.html` | name / countries[] / type(朝食/屋台/主食) | `countries[]` |

- 新エンティティを足すときは「JSON1本 ＋ 一覧の並べ方 ＋ 詳細の見せ方」をセットで決める。
- **`country` オブジェクトからは、他エンティティが正本を持つ項目を段階的に外す**（§4）。

## 4. データ設計の原則

### 4-1. 正本は1エンティティだけが持つ

| 事実 | 正本 | 参照するだけ |
|---|---|---|
| 「パンダは中国にいる」 | `animal: panda` の `countries:["cn"]` | 中国の国ページ（animals.json から join して表示） |
| 「あの旗は汎アフリカ色」 | `flag_motif: pan_african` の `countries[]` | 各国ページ・国旗ページ |
| 「ありがとう＝ケニアではアサンテ」 | `phrase: thanks` の language 配列 | 国ページ |
| 首都・人口・通貨・面積・政体 | `country` | 首都ページ等 |

→ **同じ事実を2か所に手入力しない。** 国ページの「動物」欄は、`animals.json` を
iso2 で join した結果を表示する（`countries.json` に animals 文字列配列を持ち続けない）。

### 4-2. 結合キーは iso2（`code`）

固定番号 `id`(1-193) は表示・並び順用。エンティティ間の結合は必ず `code`（iso2小文字）。

### 4-3. volatile な値は出典必須（さくらの共通ルール）

- 人口・通貨レート・GDP など変動値は `sources: [{url, checked:"2026-08-31"}]` を必須。
  ページに「◯年◯月時点」を表示。
- **memory から書かない・創作しない。** ことわざは日本語で検証できる一次資料があるものだけ。
  無い国は `proverb` 空、`greeting` で代替。
- ⚠️ commit `b4f8b03` で193か国を「一般知識で補完」済み。**この分は未検証**。
  各扉を作り込むタイミングで、その扉が使う項目を出典付きで検証・修正していく。

## 5. カテゴリーページ仕様（横テーマ）

共通：主役エンティティのカード一覧 →（クリック）→ そのエンティティの詳細 → 関連する国へリンク。
「国ABC順グリッド」は `/countries.html` だけの構成。

### `/animals.html` ― 動物・自然
- 並べ方：**動物ごと**。グループ切替タブ ＝ 種類（哺乳類/鳥/爬虫類/両生類/魚/昆虫）／大陸／希少度（IUCN）。
- カード：動物名・アイコンorサムネ・「生息：🇰🇪🇹🇿…」・希少度バッジ。
- 詳細：説明／生息国リスト（国ページへ）／その国の国獣か否か／関連動画。
- 自然（山・川・自然遺産）は `heritage.json` type=自然 として同じページの下段 or タブ。

### `/flags.html` ― 国旗
- 並べ方：**モチーフごと**（三日月と星／汎アフリカ色／汎スラブ色／十字旗／太陽／一色地に紋章 …）。
- 各モチーフ内に、その特徴を持つ国の旗をサムネで。
- 別軸：色から探す（赤・青・緑・黒・白・黄）。
- 詳細：モチーフの意味・歴史 ／ 採用国 ／「似た旗クイズ」への動線。

### `/capitals.html` ― 首都と地図
- 並べ方：首都そのもの。ソート＝人口／標高／緯度／日本との時差。フィルタ＝内陸国／島国。
- 地図ネタ（飛び地・時差・国の大きさ日本比較）を専用ブロックで。

### `/words.html` ― ことば・雑学
- 並べ方：フレーズ（あいさつ／ありがとう／数字1-10 …）→ 言語ごとに表示、語族でグループ。
- 音声（あれば）。雑学（トリビア）はフレーズと別セクション、テーマタグで。

### `/culture.html` `/food.html`
- 濃淡が大きいテーマ。当面はランキング＋読み物形式。`dish` / 祭り / 民族衣装 を順次エンティティ化。

## 6. URL 規則

- 国：`/country.html?id=85`（現状維持）。将来 `/countries/jp/` に静的化してもよい。
- 横テーマ一覧：`/animals.html` `/flags.html` `/capitals.html` `/words.html` `/culture.html` `/food.html`
- エンティティ詳細：当面はクエリ（`/animals.html?key=giant_panda`）。増えたら個別化。
- 国旗画像：`assets/flags/<iso2>.svg`（現状維持）。
- 動物などの画像：`assets/img/animals/<key>.jpg` 等、`assets/img/<type>/` 配下。

## 7. 現状 → 目標への移行方針（大きく作り直さない）

1. **今の国レイヤーと193国旗SVGは資産。捨てない。** その上に横エンティティ層を足す。
2. `category-list.js`（国ABC順レンダラー）は「まだエンティティ化していない扉」の暫定表示として残してよいが、
   **作り込む扉から順にエンティティ方式へ置き換える**。
3. パイロット＝**動物**（§ROADMAP）。1扉をエンティティ方式で完成させ、パターンを確定させてから横展開。
4. パターン確定後：国旗 → 首都 → ことば → 世界遺産 の順で同じ作りに。
5. 各扉のエンティティ化と同時に、`countries.json` から該当項目を外し join に切替（正本の一元化）。

## 8. 著作権・正確性

- 数値：出典必須（§4-3）。
- 画像：国旗SVGは自作/パブリックドメイン相当のもの。動物写真等は権利の明確なものだけ。
- 人物：世界シリーズでは「国紹介の一部」に留める。深掘り人物録は作らない。
