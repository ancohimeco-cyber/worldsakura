### ▲ 特に注意：ことわざ

## 3. SNSで伸びやすい企画（優先順位付き）

［事実］地理・国際情勢・地図アニメ系は日本市場でまだ競合が薄く、30〜60代男性に刺さるニッチ（ラッコM&Aのジャンル情報／確認日2026-08-31）。
［事実］ショート共通で「最初の1秒」と「視聴維持率」がアルゴリズムの核（2026）。TikTok=完全視聴率、Reels=保存数＋プロフィール遷移、Shorts=登録寄与＋検索タイトル。

### ［提案］伸びやすい順

1. **国旗クイズ／国旗の意味クイズ**（「この国旗どこ？」「日本と似てる国旗3選」）。参加型＝コメント・完全視聴が伸びる。**素材が全件ある＝最優先。**
2. **"地図で見る"系**（飛び地・内陸国・時差・国の大きさ日本比較・隣接国が多い国）。地理チャンネルの本丸。既存の位置情報を可視化するだけ。
3. **世界の"○○"ランキング／比較**（物価・チップ・信号の色・コンビニ・自販機・トイレ）。日常との差＝保存される＝Reels向き。
4. **国旗トリビア「今日のへぇ〜」**（台本制作中）。1ネタ完結で量産可。定期枠に。
5. **各国語であいさつ／「ありがとう」（音付き）**。言語学習層に刺さる。単体は弱いので「10か国まとめ」で。
6. **世界の朝ごはん／屋台メシ**（飯テロ枠）。映像が強ければ伸びる。旅行アフィリ動線に最適。AI画像なら質の担保が必須。
7. 民族衣装・絶景＝ビジュアル勝負。伸びるが大手トラベルと競合。差別化しにくく優先度中。

低い：歴史・人物の深掘り＝ショートでは伸びにくい（メモにも「3分で」とある＝長尺向き）。

## 4. 検索流入（SEO）が期待できるサイトカテゴリ（優先順位付き）

［推測］キーワード需要は一般傾向からの見立て（確認日2026-08-31）。

1. **「国名＋首都」「国名＋国旗 意味」「国名＋通貨」「国名＋公用語」** — 学習・調べ物需要が安定。193か国×複数項目＝数百ページの受け皿。**国別総合ページが最強の資産。**
2. **「国名＋観光」「国名＋ベストシーズン」「国名＋治安」「国名＋時差」** — 旅行前検索。アフィリ直結。
3. **「国名＋あいさつ」「ありがとう＋○○語」** — 競合が薄く長期安定。
4. **「国旗 一覧」「首都 一覧」「世界 国旗 覚え方」** — まとめページで面で取る。
5. **「国名＋チップ」「国名＋マナー」「海外 やってはいけないこと」** — 旅行系、単価の高い層。

低い：ランキング系（「面積 大きい国」等）＝Wikipedia・大手メディアが鉄壁。差別化必須。

### ［提案］SEO設計の肝

- **静的サイトのままでOK（WordPress不要）。** 193か国×10項目≒1000ページ強でも現行 `build.py` で回る。
- **若いドメインで一気に1000ページ公開は「薄いページ量産」と見なされるリスク。** 国旗→首都→言葉…と1カテゴリずつ、1国ページも作り込んでから公開。
- 各国ページを相互リンク（隣接国・同地域・似た国旗）＝回遊とインデックスが進む。
- **Search Console登録＋sitemap提出は必須。**未完了ならここが最優先。
